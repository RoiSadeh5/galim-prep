# starter — ערכת פתיחה

קוד עובד להתחלה, במקום דף לבן. **~2,000 שורות של מנועים שכבר נבדקו**,
עם כל מה שתלוי בקורס מרוכז בקובץ אחד.

חוסך את שלבים 3–5 במדריך (מנוע הנפשה · מרכז תרגול · סימולטור).

---

## איך מתחילים

**1. העתק את התיקייה** לתיקיית הפרויקט החדש:

```bash
cp -r "starter" ~/Desktop/Projects/<שם-הקורס>-prep && cd ~/Desktop/Projects/<שם-הקורס>-prep
```

**2. ערוך את `config.js`** — רק אותו. שם הקורס, קידומת אחסון, משך המבחן,
משבצות המבחן, ומיפוי הקטגוריות לעמודי הנושא.

**3. הרץ מקומית** ובדוק שנפתח:

```bash
python3 -m http.server 8000
```

ואז פתח http://localhost:8000

**4. מלא תוכן** — עמודי הנושא ב-`index.html`, השאלות ב-`questions.js`.

## מה עובד כבר עכשיו

- ✅ סרגל צד ימני קבוע, נגלל, שהופך לפס עליון בנייד
- ✅ מצב כהה/בהיר שנשמר
- ✅ ניווט בין מקטעים עם `#hash`
- ✅ מרכז תרגול: מאמן אדפטיבי, מחברת טעויות, סינון, חיפוש, עורך קוד
- ✅ סימולטור מבחן: משבצות מהקונפיג, שעון, בדיקה אחרי כל שאלה
- ✅ מנוע הנפשה: 11 סוגי ויזואל + נגן שלבים
- ✅ נגן שלבים לעמודי הנושא (`mountPlayer`)

**נבדק:** השלד הורץ בדפדפן עם קונפיג לדוגמה — שלושת המצבים נטענים,
הקישורים מהקונפיג עובדים, ומנוע ההנפשה מצייר.

## סדר טעינת הקבצים

חשוב — אל תשנה:

```
config.js  ⟵  נתונים (questions, walkthroughs)  ⟵  מנועים
```

המנועים קוראים את `window.COURSE` בזמן הטעינה.

---

## התאמת מנוע ההנפשה לקורס אחר

הסוגים הקיימים מתאימים למבני נתונים. לתחום אחר מוסיפים סוג ב-`viz.js`:

1. פונקציה שמקבלת `spec` ומחזירה HTML
2. רישום ב-`RENDERERS` בתחתית הקובץ
3. CSS למחלקות החדשות ב-`index.html`

**דוגמאות לתחומים אחרים:** מעגלים חשמליים ⟵ `circuit` ·
אותות ⟵ `waveform` · כימיה ⟵ `reaction` · סטטיסטיקה ⟵ `distribution`
